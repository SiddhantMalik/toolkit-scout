Is TranscriptAPI free? You can start for free: new accounts get 100 free credits, no card required, and one transcript costs one credit. After that, the paid plan is $5 a month for 1,000 credits per month, or $54 a year billed annually. Is TranscriptAPI the same as youtubetranscriptapi? No. TranscriptAPI is a hosted REST API, separate from the open-source YouTubeTranscriptApi Python package, which fetches transcripts from your own machine. TranscriptAPI is managed and also adds YouTube search, channel browsing and playlist extraction. Can I use it from Python or JavaScript? Yes. TranscriptAPI is a REST API, so any language that can send an HTTPS request with a Bearer API key can call it, including Python and JavaScript with Node.js. The API reference includes complete code examples in cURL, Python and JavaScript. Quickstarts: Python , JavaScript , cURL Does it use my YouTube Data API quota? No. You sign in with your own TranscriptAPI credentials: an API key, or OAuth for some MCP clients. You do not need a Google or YouTube Data API key, so no YouTube Data API quota of yours is used. Usage is counted in TranscriptAPI credits instead. Does it work with AI agents (MCP)? Yes. TranscriptAPI runs an MCP server at https://transcriptapi.com/mcp. The MCP docs have setup guides for Claude and ChatGPT, which connect with OAuth, and OpenAI Agent Builder, which uses an API key. It works with any MCP-compatible client, and MCP calls use the same credits as the REST API.
