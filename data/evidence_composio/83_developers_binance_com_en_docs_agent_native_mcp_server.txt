[Model Context Protocol](https://modelcontextprotocol.io/) (MCP) is an open standard that lets AI agents and coding assistants connect to external tools and data sources over a single, well-defined transport — instead of every integration needing its own custom API glue.

Trading

Binance MCP Server

Connect your AI agent to Binance to read market data, check balances, and trade Spot / Margin / Convert / Futures inside a dedicated Agentic sub-account.
