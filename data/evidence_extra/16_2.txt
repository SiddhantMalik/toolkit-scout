MCP is an open standard that lets AI applications, such as ChatGPT and Claude, connect securely to outside tools and data sources. Instead of copying and pasting information back and forth, an MCP-compatible AI client can read and act on data directly, inside the permissions you grant it. What is LiveAgent's MCP server? LiveAgent's MCP server lets you connect an MCP-compatible AI client, like ChatGPT or Claude, directly to your LiveAgent account. Once connected, the AI client can search tickets, read conversations, add tags, and take other actions you've approved, without an agent copying data between apps. What can a connected AI tool do in LiveAgent? A connected AI tool can search and read tickets, view ticket messages and knowledge base articles, tag, assign, transfer, resolve, and reopen tickets, list agents and departments, and reply to WhatsApp conversations where that channel is enabled. Every action still respects the permissions of the account it connects as. How is access secured? There are two ways to connect an AI client: an MCP access token you generate in your LiveAgent profile, or, for clients that support it such as claude.ai, an OAuth 2.1 sign-in with a consent screen where you approve which account the AI client acts as. Access tokens are scoped, and every ticket-level action is checked against that account's own department and role permissions before it runs. Which AI clients work with LiveAgent's MCP server? ChatGPT, Claude (claude.ai, Claude Desktop and Claude Code), Cursor and any other AI client that supports the Model Context Protocol can connect. The connection is built on the open MCP standard rather than a single vendor's client, so new MCP-compatible tools work too. Which plans include the MCP server? The Business and Enterprise plans, and the free 30-day trial.
