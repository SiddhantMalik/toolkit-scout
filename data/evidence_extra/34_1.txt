# HighLevel API
> HighLevel API is the REST API of the HighLevel platform (ad-publishing, affiliate-manager, agent-studio, associations, blogs, brand-boards, businesses, calendars, campaigns, chat-widget, clientportal-ai, companies, ...). This is an LLM-friendly index of its reference documentation, generated from the OpenAPI specs at build time.
- Base URL: https://services.leadconnectorhq.com (append the endpoint path).
- Every request must send a `Version` header whose value is the API version name, e.g. `Version: v3`. Published versions: v3 (latest), 2023-02-21, 2021-07-28, 2021-04-15.
- Every authenticated request sends `Authorization: Bearer `.
## Authentication
- OAuth 2.0 access token: issued to an app through the authorization-code flow ([POST /oauth/token](https://marketplace.gohighlevel.com/docs/ghl/oauth/get-access-token.md) exchanges the code or a refresh token). A token is issued either for a Sub-Account (location) or for an Agency (company).
- Private Integration Token (PIT): a static token created in the Sub-Account or Agency settings with a chosen set of scopes; it is sent exactly like an access token. Endpoints marked "OAuth access token only" reject PITs.
- Sub-Account vs Agency: every endpoint states which token type it accepts. An Agency access token can be exchanged for a Sub-Account token with [POST /oauth/location-token](https://marketplace.gohighlevel.com/docs/ghl/oauth/get-location-access-token.md).
- Scopes: every endpoint lists the scopes it requires; the token must carry all of them (requested during OAuth authorization, or selected when the PIT is created).
## Instructions for LLMs
- Default to the latest version, v3, unless the user names another version.
- Always send `Version: ` with the version whose documentation you used (`Version: v3` for the latest). Never mix endpoints or schemas from different versions in one integration.
- Call https://services.leadconnectorhq.com followed by the endpoint path; replace `{param}` placeholders with path parameter values.
- Pick the token type, OAuth/PIT method and scopes from the endpoint's Auth line.
- Find endpoints in the version's llms.txt, then read the service `.md` file or the endpoint `.md` file for the full request and response schema.
