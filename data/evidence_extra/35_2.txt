An API key authenticates requests against your own Mailchimp account. Here’s how
to create one: 
 Navigate to the API Keys section of your Mailchimp account. 
 Click Create New Key and give it a descriptive name that tells you which application it’s used for. 
 Copy the generated key immediately and store it in a secure location. You won’t be able to see or copy the key once you finish generating it. 
 Note : An API key grants full access to your account. Keep it as secure as
you would a password, and don’t use one in a browser or a mobile app; see
 API keys for why.
