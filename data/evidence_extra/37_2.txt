Introduction to MCP MCP (Model Context Protocol) is a standard that enables AI assistants (such as ChatGPT or Claude) to connect securely to external platforms. With MCP, you can use natural language commands to interact with your systeme.io data. For example, you can ask ChatGPT to find a contact or add a tag just by typing a sentence. Our MCP feature currently provides direct access to specific contact-management features, allowing you to use AI to manage your contacts, tags, and contact fields. 2. How the systeme.io MCP server works The systeme.io MCP server allows AI applications to access specific contact-management tools within your account. It creates a bridge between: The host : Your AI tool (e.g., ChatGPT, Claude). The server: Your systeme.io account. Once connected, the AI can execute commands to manage your contacts and tags automatically. For technical details, please refer to our official MCP documentation: https://developer.systeme.io/docs/mcp-server 3. Generating your MCP keys To connect an AI tool, you first need to generate a secure MCP key. Click Settings (1), then select MCP & API keys (2) under Connections in the left-hand menu. Scroll down to the MCP keys section and click Create (3). Give your key a name (4), set an expiration date (5), and click Create (6). Your key is now ready. 4. Using the systeme.io MCP server You can use AI tools to perform the following actions: a. Contact management: Create and update contacts: Add new contacts or update existing ones. Delete contacts: Remove contacts from your list. List and retrieve contacts: Use filters to list contacts or fetch specific contact details. Manage tags: Create, assign, list, and remove tags from contacts. Retrieve contact fields (custom fields): List available contact fields and their identifiers (slugs) so the AI can correctly fill in and update contact information. For more information about contact management using the MCP server, check out our dedicated help article: How to manage your contacts with the systeme.io MCP server . b. Newsletter and campaign management: Newsletters: Create new drafts, update existing ones, target audiences (using include/exclude tags), configure sender details, schedule or remove scheduling, send test emails, send newsletters directly, delete drafts, and fetch specific newsletters. Campaigns: Create, retrieve, update, and delete entire email campaigns, as well as individual campaign steps. Email statistics: Retrieve performance statistics for your newsletters, campaign emails, and automation emails. You can fetch totals for a specific period (up to 31 days) with a daily breakdown, results for each email sent during that period, or all-time results for a specific email. Statistics include sends, opens, clicks, bounces, and spam reports. For more information about newsletter and email campaign management using the MCP server, check out our dedicated help article: How to manage your newsletters and email campaigns with the systeme.io MCP server . Note on newsletters and campaigns: Newsletters created via MCP will automatically use the default sender name and email address configured in your account settings. For email campaigns, scheduling and activating campaign steps is not yet supported through MCP and must be managed manually. Retrieving per-recipient details and specific link-click statistics is not currently supported. For sensitive actions like scheduling, sending, or deleting newsletters, the AI will ask for your confirmation before proceeding. c. Funnel management: Create funnels, opt-in steps, and webinar funnels: Use your AI tool to easily create new funnels, add opt-in steps to your funnels, and create webinar funnels with all the necessary webinar steps, including registration, thank you, and webinar broadcast pages. List and retrieve funnels: Browse through your existing funnels, opt-in steps, and webinar pages, or search for specific ones. Regenerate page content (webinar pages): Regenerate the full content of a webinar page. For more information about funnel management using the MCP server, check out our dedicated help article: How to manage your funnels with the systeme.io MCP server . Notes: Currently, modifying (editing) funnels and funnel steps via MCP is not supported. Deleting funnels, funnel steps, and webinar pages through MCP is also not supported at this time. While AI can regenerate the content of a webinar page, small targeted edits are not currently supported (it can only replace the funnel step's full content). d. Price plan and coupon management: Create, edit, and delete items: Use your AI tool to easily generate new price plans and coupons, or modify and delete existing ones. List and search: Browse through all your existing price plans and coupons, or search for specific items. For more information about price plan and coupon management using the MCP server, check out our dedicated help article: How to manage your price plans and coupons with the systeme.io MCP server . e. Automation rules and workflows management: Create automation rules: Easily connect common events and actions without configuring them manually in your dashboard. Currently, you can create rules using the following triggers: Tags ( Tag added, Tag removed ), Courses ( Enrolled in course, Course completed, Lecture completed, Module completed ), Sales ( Subscription payment failed, New sale, Sale canceled ), Funnel form subscribed, Campaign completed, Booking created, and Page visited . And the following actions: Tags ( Add a tag, Remove a tag ), Courses ( Enroll in course, Revoke access to course ), Unsubscribe from campaign, Send webhook, and Send SMS . List and retrieve automation rules: Browse your automation rules or fetch a specific rule by its ID. Create and manage workflows: Create, list, activate, and deactivate workflows directly through the chat. Configure workflow steps: Build workflow sequences using the following trigger: Funnel form subscribed , Tag added & Tag removed, Campaign completed, Enrolled in course, Course completed, Lecture completed & Module completed, Subscription payment failed, New sale & Sale canceled, Booking created & Page visited . The following action: Add a tag & Remove tag, Revoke access to cours, Subscribe to campaign & Unsubscribe from campaign, Send webhook, Send email to a specific address & Send SMS . The following delay: Wait until a specific date and time, with timezone support. You can also add YES/NO branches based on tags, registration date, last activity date, or contact status, including whether a contact has made a payment. For more information about automation rules management using the MCP server, check out our dedicated help article: How to manage your automation rules and workflows with the systeme.io MCP server . f. Digital product management: Create, view, update, and delete:  Fully manage your digital products using your AI tool. List and search: Browse your existing digital products or search for specific ones. Link price plans: Create a new digital product and price plan together, or link an existing price plan directly to a digital product. Connect to selling flows:  Programmatically connect digital products to your selling flows (order forms, upsells, downsells). For more information about digital product management using the MCP server, check out our dedicated help article: How to manage your digital products with the systeme.io MCP server. g. Physical product management: Create, view, update, retrieve, and delete:  Fully manage your physical products using your AI tool. Connect to selling flows: Easily connect your physical products to selling flows (as order forms, upsells, and downsells). For more information about physical product management using the MCP server, check out our dedicated help article: How to manage your physical products with the systeme.io MCP server . h. Offers and sales settings management: Create and configure offers: Set up offers for your selling flows, such as order forms, upsells, and downsells. Manage sales settings: Configure detailed settings for your offers, including coupons, order bumps, currency, payment methods, tax settings, affiliate commissions, payout delays, and sales limits. You can also easily attach your digital and physical products directly to these offers. i. Calendar bookings management: Create, update, and delete events: Generate new booking calendar events, or easily modify and delete existing ones. Availability: Adjust when bookings can happen directly through AI by managing Weekly availability, Date-specific availability, and Unavailability periods. List and search events: Retrieve a list of your booking calendar events or search for specific ones by name. Retrieve event details: Fetch full details for a specific event, including its locations, availability, time zone, date range, and reminders. List and filter bookings: Retrieve a list of your calendar bookings and filter them by event, status, and date range. Note on calendar events: Updating an existing calendar event's type is not currently supported through MCP. j. Course management: For more information about calendar booking management using the MCP server, check out our dedicated help article: How to manage your booking calendar with the systeme.io MCP server . j. Course management: Courses: Create, edit settings, delete, list, retrieve, activate, and deactivate courses. List course page templates and choose a theme for your course. Modules: Create, edit, delete, list, and retrieve modules to structure your courses. Lectures: Create, edit, delete, add delays, enable comments, list, retrieve, activate, and deactivate lectures. k. SMS template management: Create, edit, and delete: Generate new SMS templates, or modify and remove existing ones you no longer need. List and search: Retrieve a list of your existing SMS templates or search for specific ones. Notes: For security reasons, MCP keys are valid for a maximum of 90 days . You can create a maximum of two MCP keys at a time. This is an  initial release implementation  and does not yet support the recommended authentication method (OAuth). So you may experience minor stability issues. OAuth support is currently planned . Once released, it will improve security and eliminate the need for key expiration. Did this answer your question?
