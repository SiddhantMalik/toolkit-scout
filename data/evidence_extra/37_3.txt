What you will need: A systeme.io account An MCP key generated from your systeme.io account ( How to use the systeme.io MCP server (Model Context Protocol ) A Claude account (The feature is available for all plans) You can connect systeme.io to Claude using their Connectors feature. This works on Claude.ai (Web), the Claude desktop app, and Claude mobile apps. To do so, log in to your Claude account; on the left panel, select Customize (1). Then select Connectors (2). Click Add (3), then click Add custom connector (4). In the setup popup, enter the following details: Name (5) : systeme.io Remote MCP server URL (6) : https://mcp.systeme.io/mcp?mcpKey=YOURMCPKEY Note: Replace YOURMCPKEY with the MCP key you created on your systeme.io account. Click on Continue (7). Select No sign-in (8) under Authentication, and click Add (9). Once connected, you'll see the systeme.io connector panel with a list of tools Claude can use on your behalf. These are divided into two categories: a. Read-only tools (10): These let Claude retrieve information from your systeme.io account without making any changes (more options are available as you scroll). b. Write/delete tools (scroll further down) (11): These allow Claude to create, update, or delete data in your account (more options are available as you scroll). For each tool, you can choose one of three permission levels that will apply to all the tools: Always allow (12) Needs approval (13) Blocked (14) Custom (15): Each tool can be configured individually according to your preference. Once connected and all set, click the + button in the chat input, select Connectors , and toggle systeme.io on. Claude will now have access to your systeme.io account in this conversation.
