Removed : The catalog and cart tools on https://{shop}/api/mcp were removed. Use Shop MCP instead, or build directly on the Universal Commerce Protocol (UCP) . For the deprecation announcement, refer to the developer changelog . Storefront MCP let AI agents search a store s catalog and manage carts over the Model Context Protocol (MCP). UCP now provides these capabilities at https://{shop}/api/ucp/mcp . Anchor to Choose your path Choose your path If you re a merchant and want to add AI chat to your online store without writing code, then use the Inbox agent in Shopify Inbox. Before you start, check the Inbox agent requirements . If you re a developer or you build a third-party AI assistant, then start with Shop MCP . Refer to the tool map if you d rather keep calling each store s UCP endpoint yourself as Storefront MCP did. To compare the two paths, refer to the Agentic commerce overview .
