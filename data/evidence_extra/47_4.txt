# Does Ecwid offer an official MCP server Ecwid’s documentation does **not mention an official MCP server**. It does document a [REST API calls](https://docs.ecwid.com/api-reference/advanced/rest-api-calls.md) for store data, accessed with an app and access tokens. The docs don’t say that this API is available through MCP.
