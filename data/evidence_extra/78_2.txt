Manage type of access Read only, write only, and more granular controls coming soon. Frequently asked questions What is MCP and how does it work with Superhuman Docs? MCP (Model Context Protocol) is an open standard that lets AI tools work directly inside your other tools. Superhuman Docs runs an MCP server built on this standard so when you connect an AI like Claude or ChatGPT, it gains the ability to read, analyze, and update your docs on your behalf. Instead of working in Superhuman Docs, you can prompt in the chat window of your chosen AI tool, and the AI carries it out directly in your doc. What Superhuman Docs plan do I need to use MCP? MCP is included on all paid plans. While rate limits do apply, they are high and should not interfere with reasonable MCP usage. Free plan users can try it out with read-only access for up to 30 requests per week (with a max of 60 requests per month). How do I set up a connector? You can find all our available MCP connectors and setup instructions in our help center. Where can developers learn more about Docs MCP? You can learn more about Docs MCP in our help center.
