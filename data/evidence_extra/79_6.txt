Who can use this? Plans: Business Enterprise USM Content Generate an access token At the bottom of the left navigation bar, select your Account (profile image), then go to Personal Settings . Your personal settings show in the new window. Navigate to the API Access tab and select Generate new access token . Brandfolder Image A window displays, prompting you to name your token. Name your token and select OK . A newly generated access token displays. Copy the token value and store it safely (for example, in a password manager). Make sure to copy the token value because this is the only time it's visible. Select OK . Smartsheet returns you to the Manage API Access Tokens page and displays your new access token by name. You've now generated a valid Smartsheet API access token for calling Smartsheet API operations. You can also revoke (delete) API access tokens in the API Access > Manage API Access Tokens page.
