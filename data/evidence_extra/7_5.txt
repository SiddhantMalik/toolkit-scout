 Zoho CRM V8 APIs Zoho CRM V8 APIs Metadata APIs Fetch the metadata of modules, fields, layouts, custom views, and related lists. Core APIs Perform CRUD operations on CRM module entities and integrate with any third party application through flexible RESTful endpoints. Composite API Combine up to five API calls in a single request through this API. Bulk APIs Push and retrieve data from Zoho CRM in bulk using a set of asynchronous APIs. Notification APIs Get notified whenever a data change occurs inside your CRM. Query APIs Fetch records using the SELECT query(SQL syntax) from Zoho CRM.
