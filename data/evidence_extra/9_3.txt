Only Admin users are able to generate API Keys. To generate an API Key... Navigate to Settings > Integrations > API Keys. Click the 'Generate API Key' button. Once your API Key is produced, you'll be able to see when it was generated and give it a label to differentiate its usage from other API Keys you may generate in the future. ​ This page will only show API Keys you've generated; each Admin user can generate their own. You can delete an API key at any time by clicking the trash can icon at the right: We also have API documentation available for more advanced users. ​ Note: For the Zapier integrations, please go to 'Settings' > 'Integrations,' and generate a token there.
